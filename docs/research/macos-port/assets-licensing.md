# macOS Fork Asset Licensing Review

Research question: [Nightchamp/arknights-frame-assistant#14, “核对可复用品牌与图像资源的授权边界”](https://github.com/Nightchamp/arknights-frame-assistant/issues/14).

Checked 2026-08-08. This report interprets the cited license and permission records for release planning; it is not definitive legal advice. Internet research used `agent-reach` with the GitHub (`gh`), Exa, and OpenCLI web backends. Only repository records and other primary sources are cited.

## Conclusion

The repository-authored program is offered under **GPL-3.0-only**, but that conclusion reaches only material whose copyright holders could make that grant. It does not turn third-party game pixels, character art, names, or marks into GPL-covered material. The current evidence supports these release boundaries:

- Reuse repository-authored source under GPL-3.0-only, preserving notices, identifying modifications, and providing corresponding source when distributing a macOS binary.
- Do not carry `logo.png` or `logo.ico` into a public macOS product without a new written grant. The repository only asserts artist ownership and “仅限本开源项目” authorization; it does not contain an artist-authenticated grant clearly covering a separately branded fork, modification, or public binary/app distribution.
- As a conservative release-risk policy, remove or independently replace all 23 apparently game-derived UI templates before public distribution. Their commits establish why they were added, not their capture provenance or permission to redistribute any underlying Arknights imagery.
- Use a distinct product name and original, game-neutral icon. Refer to “明日方舟 / Arknights” only as needed to describe compatibility, with a conspicuous unofficial/non-affiliation statement; the repository contains no trademark or branding permission from Hypergryph/Yostar.
- Do not use gameplay screenshots in repository/app-store marketing unless permission is obtained or a jurisdiction-specific review supports that exact use. This is a release-risk policy rather than a conclusion that every small UI fragment is independently copyrightable. Prefer original mockups or diagrams without game pixels or marks.

## Governing Source Record

### Repository and GPL record

- The upstream README names the product “明日方舟帧操小助手 ArknightsFrameAssistant”, displays `logo.png`, and states that the program uses “GNU General Public License v3.0 only” ([README at reviewed commit](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/README.md#L1-L14), [license declaration](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/README.md#L248-L252)). `CONTRIBUTING.md` separately says code contributions are released under GPLv3 ([contribution terms](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/CONTRIBUTING.md#L309-L311)).
- GPLv3 defines the “Program” as a copyrightable work licensed under it and a “covered work” as that Program or a work based on it ([GPLv3 §0](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/LICENSE#L73-L101)). It also says program output is covered only when the output itself constitutes a covered work ([§2](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/LICENSE#L154-L162)). These provisions do not establish ownership of independently copyrighted material merely because it is present in the repository.
- A public modified source release must retain notices, mark modifications and dates, and license the covered work under GPLv3; object-code distribution must provide corresponding source by a §6 method ([§§4-6](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/LICENSE#L195-L249)).
- GPLv3 expressly distinguishes copyright permissions from trademark limits and permits terms that decline trademark rights ([§7(e)](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/LICENSE#L343-L405)). It therefore supplies no basis for treating Hypergryph/Yostar marks as project assets.
- The README also requests “请勿用于商业用途” ([README](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/README.md#L248-L253)), while GPLv3 permits charging for conveyed copies and prohibits further restrictions on recipients ([§4](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/LICENSE#L195-L206), [§10](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/LICENSE#L446-L469)). On the face of these sources, the sentence is inconsistent with the stated GPL-3.0-only grant if read as an additional license restriction. It should not be used to infer that third-party game assets may be distributed under a “non-commercial GPL”. Maintainer clarification would be useful, but it would not cure missing third-party permissions.
- GPLv3 itself says that conflicting obligations do not excuse compliance and, if both cannot be satisfied, the covered work may not be conveyed ([§12](https://github.com/CloudTracey/arknights-frame-assistant/blob/645af9608c782dfe70bf285c1e836f1be8ac2daf/LICENSE#L540-L550)). GPL §5 also distinguishes independent works distributed in an aggregate. The present record does not establish whether each image is part of the GPL-covered work or a separately licensed aggregate asset, but a project-only or non-commercial image permission is not a clean basis for a uniformly reusable public release.

### First-party Arknights records

- The Chinese App Store listing identifies the product as “明日方舟”, its developer/provider as Shanghai Hypergryph Network Technology Co., Ltd./上海鹰角网络科技有限公司, and its copyright as “© 2017-2019 Hypergryph Co., Ltd.” ([official App Store product record](https://apps.apple.com/cn/app/%E6%98%8E%E6%97%A5%E6%96%B9%E8%88%9F/id1454663939)). It also confirms that the iPhone/iPad app can run on Apple-silicon Macs; platform compatibility is not an asset license.
- Hypergryph’s current game agreement defines “游戏内容” to include names, titles, signs, symbols, designs, likenesses, images, maps, items, scenes, audiovisual clips, and similar elements (§1.7). Its §§4.1-4.5 grant users a personal, non-commercial, non-transferable game-use license and state that copying, adapting, communicating, publishing, distributing, or otherwise using game content outside that scope requires Hypergryph’s express written consent. Section 9.1 states that rights in the game software, service, and game content, including trademarks and copyright, belong to Hypergryph except where another right holder owns them ([鹰角网络游戏使用许可及服务协议](https://user.hypergryph.com/protocol/ak/service)).
- Yostar’s global terms similarly identify game titles, images, logos, trademarks, characters, artwork, audiovisual effects, and related rights as Yostar or licensor content and reserve uses not expressly permitted ([Yostar Terms of Service, §5](https://yo-star.com/en-us/terms_of_use)). This corroborates the third-party-content classification for the global edition; it is not a substitute grant for Chinese-edition assets.
- Yostar’s official Arknights re-creation guidelines allow compliant individuals/non-profit organizations to publish non-commercial derivative works that promote the game, but prohibit works containing no or little original content that directly copy, scan, sample, or trace in-game illustrations, video, audio, music, or similar material ([Terms and Conditions of Re-creation](https://www.arknights.global/fankit/guidelines)). The apparently game-derived, minimally transformed UI templates do not fit that stated derivative-work permission.
- The official fan-kit artwork license is narrower still: it covers only designated wallpapers and stickers, only on private social accounts for non-commercial study/research/discussion, and bars transfer, sale, sublicensing, commercial use, and use to promote other goods or services ([Fan-kit Terms and Conditions of Use, §§1-3](https://www.arknights.global/fankit/precautions)). It does not cover repository screenshots, UI templates, project branding, or app icons.

## Third-Party Marks and Game Content

The following should not be presented as covered by AFA’s GPL statement:

- “明日方舟”, “Arknights”, Hypergryph/鹰角网络, Yostar, game logos, character names/likenesses, Rhodes Island and other in-world identifiers, and the recognizable game UI. Hypergryph’s agreement categorizes names, titles, signs, symbols, designs, likenesses, images, maps, items, and scenes as game content and reserves related trademark/copyright rights.
- AutoHotkey names/logos and Windows/Microsoft, GitHub, Shields.io, and MAA marks. Their appearance as links, remote badges, or vendored upstream documentation is not a transfer of brand rights to AFA.
- The commissioned project logo’s underlying subject matter. The repository asserts artist ownership and a narrow AFA permission, but contains no artist-authenticated grant, does not identify the depicted subject, and does not document authorization from any underlying game right holder.

A non-affiliation notice helps avoid a misleading presentation but is not itself permission to copy artwork, screenshots, or marks.

## Unresolved Provenance Gaps

1. The actual artist permission for `logo.png`/`logo.ico` is not in git: no signed message, license text, date, territory, duration, modification right, redistribution right, or macOS/fork/app-store scope was found.
2. The logo’s depicted subject and any underlying Arknights character, costume, symbol, or other game rights are not identified or cleared in repository records.
3. No `TakeOverButton` or level-template file records the source screenshot, game edition/version, capture date/device, captor, transformation steps, or permission from Hypergryph/Yostar.
4. No first-party record was found granting this project the right to redistribute Chinese-edition game pixels under GPL-compatible terms. Hypergryph’s current agreement instead calls for express written permission outside personal game use.
5. Yostar’s global re-creation and fan-kit terms are not a grant for the Chinese edition and, on their own wording, do not authorize direct UI crops or GPL-compatible redistribution.
6. No upstream permission was found for a separate macOS product to keep the full AFA name/identity. There is also no repository trademark inventory or mark policy.
7. The 20 level templates remain extracted even though current level detection is color-based; whether any macOS implementation needs them is unresolved.
8. The exact AutoHotkey docs provenance is identifiable, but a repository-wide license for its documentation screenshots and logos was not found in the first-party docs repository.
9. No current full gameplay screenshots are tracked. Any future screenshots would need their own asset log and release decision rather than inheriting the conclusion for source code.

## Concise Recommendation

As a conservative release policy, publish the macOS fork as a GPL-3.0-only code distribution with a distinct name and newly created, game-neutral icon. Before the first public source or binary release, remove all 23 apparently game-derived UI templates and avoid gameplay screenshots; implement color/geometry or user-local calibration instead. If a game image or the current logo is indispensable, establish provenance and obtain written permission from the relevant right holder(s) covering the intended public source and binary use, modification, and downstream redistribution, then store that record plus any required attribution beside an asset manifest. Keep “Arknights / 明日方舟” to a factual compatibility statement with a clear unofficial/non-affiliation notice as a risk-control measure, and exclude the Windows/AutoHotkey documentation image bundle from the macOS application.
